# Product Overview

## 서비스 개요

ForHome은 가족 구성원이 집안일, 육아 담당, 내일 할 일, 가족 메시지를 함께 관리하는 웹 앱이다. Firebase Hosting으로 배포되는 정적 웹 앱이며, 로그인한 가족 구성원이 동일한 Cloud Firestore 문서를 공유 상태 저장소로 사용한다.

## 코드에서 확인된 내용

- 서비스 이름은 ForHome이다.
- 주요 목적은 가족 집안일 관리이다.
- 프론트엔드는 `code/index.html` 단일 파일로 구현되어 있다.
- 운영 배포는 Firebase Hosting을 사용한다.
- 공유 앱 데이터는 Cloud Firestore의 `families/forhome/state/app` 문서에 저장된다.
- 로컬 개발 서버는 운영 API 서버가 아니라 정적 파일 테스트 서버이다.
- 로컬 `localhost` 접속 시 기본적으로 Firebase 대신 브라우저 `localStorage` mock 저장소를 사용한다.
- GitHub Actions가 Firestore 상태를 날짜별 JSON/Markdown 보고서로 백업한다.
- Windows 작업 스케줄러와 Kakao memo-to-me API를 통해 아침 브리핑을 보낼 수 있다.

## 사용자가 얻는 가치

- 가족 구성원별 집안일 기록을 한곳에서 볼 수 있다.
- 완료한 집안일은 바로 점수화하지 않고 검토자 승인 후 반영한다.
- 엄마와 아빠의 상호 승인, 아이 관련 작업의 양부모 승인 같은 가족 규칙을 앱에 반영한다.
- 사진 또는 메모로 집안일 증빙을 남길 수 있다.
- 내일 할 일을 요청하고 수락 또는 거절할 수 있다.
- 아침 7시 브리핑으로 전날 기록과 오늘 계획을 확인할 수 있다.

## 추정한 내용

- 현재 구현은 가족 내부의 소규모 사용을 전제로 한다.
- MVP의 핵심 대상 사용자는 엄마, 아빠, 자녀, 관리자 계정으로 보인다.
- 장기적으로는 집안일 분담의 공정성, 피로도 관리, 가족 커뮤니케이션을 하나의 생활 운영 도구로 묶는 방향이 적합하다.
